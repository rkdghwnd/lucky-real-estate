# 행운부동산공인중개사사무소 — 웹사이트 & GTM 설계 문서

- **작성일:** 2026-07-03
- **대상 사업자:** 행운부동산공인중개사사무소 (인천광역시 서구 오류동)
- **주력 분야:** 공장 · 창고 · 토지 (B2B / 투자자 대상, 건당 고가)
- **작성 맥락:** 개발자(조력자)가 초기 시스템·전략을 1회 구축. 사업자는 60대 후반, 컴퓨터에 익숙하지 않음. 개발자의 지속적 유지보수 개입 불가.

## 1. 핵심 제약 (모든 설계 결정의 기준)

> **운영비 0원에 가깝게 + 유지보수 거의 0 + 컴퓨터에 익숙하지 않은 60대 후반 사장님(단독 운영) + 개발자의 지속적 개입 불가**

이 제약이 최우선이며, 어떤 기능도 이 제약과 충돌하면 **더 단순한 대안으로 대체하거나 제거**한다.

## 2. 비즈니스 전략 & 포지셔닝

### 2.1 한 줄 포지셔닝
> **"인천 서구 공장·토지, 25년 네트워크. 네이버에 없는 물건까지 연결합니다."**

### 2.2 차별점(USP) = 네트워크
- 25년 경력 + 인천 토박이 = **밸류맵·디스코 같은 데이터앱이 못 가진 자산.**
- 공장/토지의 좋은 물건은 공개 플랫폼에 안 올라옴(비공개 매물). **네트워크 있는 중개사에게만 연락이 옴.**
- 데이터앱은 "얼마에 팔렸나"는 알아도 "왜 파는지, 얼마까지 되는지, 옆 필지가 곧 개발되는지"는 모름 → **현장 25년만 아는 정보.**

### 2.3 웹사이트의 3가지 역할
1. **신뢰 앵커** — 큰돈 거래일수록 "이 사람 진짜 전문가네, 믿고 전화하자"를 만든다.
2. **초지역 전문 콘텐츠 허브** — 오류동·검단·인천 서구 공장/토지 정보를 쌓아 로컬 SEO를 장악한다.
3. **전속·독점 매물 쇼케이스** — "이 사무소가 직접 가진 매물"을 깔끔히 진열한다.

### 2.4 전략적 귀결
- **적게 보여주고 전화로 연결.** 공개 매물은 소수 + "비공개 매물은 전화" → 관리 부담↓ + 희소성↑ + 전화 유도. (매물 6개가 약점이 아니라 전략)
- 이 포지셔닝이 제약(고령·전화중심·유지보수0)과 정확히 맞아떨어진다.

### 2.5 설계 관통 5원칙
1. **전화 우선** — 고령 사장·고령 고객, 모든 길은 전화로.
2. **적게 보여주고 연결** — 네트워크 전략.
3. **무료·무유지보수** — 정적 SSG + 무료 티어, 깨질 자동화 배제.
4. **SEO는 원본 지역 콘텐츠로** — 스크랩·스핀 아님.
5. **원본은 우리 사이트** — 외부(카톡·블로그·플랫폼)는 링크·붙여넣기로 유입만.

## 3. 대상 사용자
- **매수자:** 공장/창고/토지를 찾는 제조업체·투자자(B2B). 네이버 검색 + 전문 플랫폼에서 움직임. 연령대 있음.
- **매도자:** 조용히 제값에 팔고 싶은 지역 지주·공장주. (물건 확보 = 매수자만큼 중요)
- **운영자:** 60대 후반 사장님(단독). 컴퓨터 미숙, 스마트폰/카톡은 사용. 필요 시 가족이 원격 조력 가능.

## 4. 사이트맵 & 페이지별 구성

전제: **큰 글씨 · 큰 버튼 · 고대비 · 모바일 우선.** 모든 페이지에 **전화 CTA 상시 고정.**

### 공통(전역)
- 상단: 로고 + 전화번호(큼직) + 심플 메뉴(매물/소식/회사소개/문의)
- 고정 전화 CTA: 모바일=하단 고정바, 데스크톱=우측 플로팅
- 어디서든 뜨는 '찾는 매물 남기기' 모달(요청폼)
- 푸터: 중개사무소 법정 정보(상호·대표·등록번호·소재지·전화) + 네이버 지도
- **⚖️ 법적 준수(중요):** 공인중개사법상 인터넷 표시·광고 의무 — 매물별 *소재지·면적·가격·거래형태·종류* + *사무소/개업공인중개사 정보* 를 필수 명시(위반 시 과태료). 매물 카드/상세에 필수 필드로 반영.

### 홈
- 히어로: 포지셔닝 문구 + `📞 지금 전화상담` + `찾는 매물 남기기`
- 대표 공개매물 3~6개 + `전체 매물 보기`
- 비공개 매물 배너: "여기 없는 물건이 더 많습니다 → 전화"
- 최근 데이터 리포트·정보글 3~4개
- 신뢰 블록: 25년 경력·거래 사례·인천 토박이·자격

### 매물 목록
- 최소 필터: 유형(공장/창고/토지/기타) · 거래(매매/임대) · 최신순
- 카드: 사진 + 유형뱃지 + 제목 + 면적·가격·위치
- 하단: "못 찾으셨나요? 전화 주시면 비공개까지 찾아드립니다" + CTA

### 매물 상세 (핵심)
- 사진 슬라이더(스와이프 + 썸네일, 여러 장)
- 핵심정보 표: 면적(대지/건물·평/㎡) · 가격 · 용도지역 · 지목 · 도로접함 · (공장) 층고·전력·준공 · 주소
- 네이버 지도 핀(위치)
- AI 생성 SEO 본문(설명)
- 공유 버튼: 카톡 · 링크복사 · 문자
- `📞 이 매물 문의` + "비슷한 조건 더 있음 → 전화"

### 부동산 소식 (콘텐츠 허브)
- 필터: 전체 / 데이터 리포트 / 정보 가이드 / (선택) 뉴스
- 카드: 썸네일 + 제목 + 날짜 + 요약 → 글 상세(SEO 구조 + 매물·전화 CTA)
- (선택) 사이드 "부동산 뉴스" 제목만 링크아웃

### 회사소개
- 대표 인사말 + 사진 / 25년 스토리 / 네트워크 강조 / 거래 사례(익명) / 자격·등록증 / 사무소 위치(지도)

### 상담문의
- 대형 전화 버튼(모달) + 요청폼(이름·연락처·찾는 조건) → Supabase 저장 + 사장님 이메일 알림(옵션: 문자)
- 사무소 약도·영업시간 (+선택 카톡 채널)

## 5. 어드민 & 매물등록 플로우

원칙: **"폰으로, 큰 버튼, 최소 타이핑."** 개발자가 처음 1회 세팅 → 이후 사장님은 폰 홈화면 아이콘 원탭.

### 접속(로그인 최소화)
- 홈화면 아이콘(웹앱) 설치 + 로그인 상태 장기 유지 → 평소 재로그인 거의 없음
- 잠기면 4자리 PIN(비밀번호 X), URL 비공개
- 어드민은 URL 기반 → 필요 시 가족이 원격 대신 조작 가능(안전판)

### 어드민 4개 기능
1. **매물 등록/수정**
   - 플로우(한 화면, 위→아래, 큰 버튼):
     1. `📷 사진 올리기` — 폰 앨범/카메라, 여러 장
     2. 유형 `[공장][창고][토지][기타]` · 거래 `[매매][임대]` — 버튼 탭
     3. 주소 입력 → 지도 핀 자동 + 용도지역·지목 등 공공데이터 자동채움(가능 항목)
     4. 면적·가격 등 핵심 몇 칸(필수 최소화)
     5. `✨ AI 설명 만들기` → 제목+SEO 본문 초안 자동 → 그대로 저장 or 수정
     6. `저장` → 사이트 게시 + 온디맨드 갱신
   - (선택) 설명 음성 입력(폰 받아쓰기) → AI 정리
   - 수정/내리기: `[수정]` `[판매완료/내리기]` — '삭제' 대신 soft(비공개) 처리로 실수 방지
2. **데이터 리포트 생성 → 게시** — 기본 월 1회 자동, `[지금 생성]` 수동 버튼 제공
3. **네이버 블로그용 변형본 생성(복사)** — 매물/리포트에서 `[네이버 블로그용 만들기]` → **다른 톤 변형본 + 우리 사이트 링크** 생성 → `[본문 복사]` `[사진 다운로드]` → 사람이 네이버에 붙여넣기
4. **문의 수신함** — 요청폼 목록(이름·연락처·조건·시간) + `[📞 전화걸기]` + 읽음표시 / 알림: 이메일 무료 기본(옵션 문자)

### 현실 보조
- 코팅 그림 설명서 1장
- 출시 시 개발자가 매물 6개 채워두고 시작

## 6. 콘텐츠 & SEO 플랜

전략: **"넓은 키워드에서 싸우지 말고, 좁고 확실한 지역 키워드를 싹쓸이."**

### 콘텐츠 4종
1. **매물글** — 내 매물만, 등록 시 AI가 SEO글 자동 생성(우리 사이트)
2. **데이터 리포트** — 공공데이터 실거래가 → AI 정리 → 월 1회 자동 게시(무검수 안전형: AI가 정해진 숫자를 틀에 정리만 → 환각 최소)
3. **개념 가이드** — 출시 때 개발자가 10~15개 시딩(검수 1회), 이후 방치(evergreen)
4. **뉴스 위젯(선택)** — 네이버 뉴스 검색 API로 제목+요약+링크아웃(새 창). 이미지 미복사(저작권), 곁가지 위젯으로만.

### 키워드
- 거래형: `인천 서구 공장 매매`, `검단 창고 임대`, `오류동 토지`, `왕길동 공장`, `검단산업단지 공장`, `인천 물류창고 임대`
- 정보형: `공장 살 때 용도지역`, `공장 매매 체크리스트`, `토지 지목 변경`, `산업단지 입주 자격`
- 시세형: `인천 서구 토지 시세`, `검단 공장 실거래가`

### 온페이지·기술 SEO (정적 SSG 유리)
- SSR/SSG로 HTML 사전 렌더(네이버 봇 Yeti는 JS 약함)
- 매물 등록 시 title·description 메타 자동 생성(AI)
- **OG 태그(카톡 공유용) 필수** — 링크 붙였을 때 썸네일·제목·가격 노출
- 구조화 데이터(JSON-LD): `RealEstateAgent`(사무소) + 매물 스키마
- 자동 sitemap.xml / robots.txt, 지역 키워드를 title·h1·본문에 자연스럽게
- 글마다 작성자(개업공인중개사 실명·경력) 표기 → YMYL E-E-A-T 신뢰

### 검색 등록(안 하면 색인 자체가 안 됨)
- 네이버 서치어드바이저 + 구글 서치콘솔에 사이트·사이트맵 제출

### 발행 리듬
출시 시딩 10~15 + 새 매물마다 새 페이지(자연 신선도) + 월 1회 자동 리포트. **콘텐츠 treadmill 없음.**

### 출시 시딩 콘텐츠 예시(개발자 1회)
1. 인천 서구(검단·오류동) 공장 매매 가이드
2. 공장 살 때 용도지역 완전정리
3. 공장 매매 체크리스트(도로·전력·오폐수·불법건축물)
4. 토지 지목과 공장 지을 수 있는 땅
5. 산업단지 입주 자격·절차
6. 창고/물류부지 고르는 법
7. 공장 매매 세금 기초
8. 인천 서구 지역·개발호재 소개 … (총 10~15개)

## 7. GTM & 마케팅 채널 전략

한 줄: **온라인 = 전화가 울리게 만드는 깔때기, 클로징은 25년 네트워크·전화·대면.**

### 채널 우선순위 (예산 0·유지보수 0)
| 순위 | 채널 | 하는 일 | 노력 | 누가 |
|---|---|---|---|---|
| ⭐1 | 네이버 플레이스 | "오류동 부동산/공장" 지도·검색 노출 | 1회+가끔 | 개발자→사장님 |
| 2 | 서치어드바이저·서치콘솔 | 사이트 색인 | 1회 | 개발자 |
| 3 | 구글 비즈니스 프로필 | 구글 지도 노출 | 1회 | 개발자 |
| 4 | 네이버 블로그(변형본) | 네이버 검색 콘텐츠 | 가끔 붙여넣기 | 사장님/가족 |
| 5 | 매물 링크 배포 | 카톡·문자로 네트워크에 | 매물마다 | 사장님 |
| 6 | 공장 전문 플랫폼(공장나라 등) | 핵심 매물만 수동 등록 | 선택 | 사장님/가족 |

### 최우선: 네이버 플레이스 + 리뷰 엔진
- 등록·최적화: 업종(공인중개사)·사진·소개(포지셔닝)·전화·홈페이지 링크
- **리뷰가 로컬 랭킹을 좌우** → 25년 단골 자산 활용: **거래 성사 때마다 "네이버 리뷰 한 줄" 부탁 루틴**(문자로 링크). 공짜 + 최강 레버.

### 매도자(물건 확보) 사이드
- 웹 회사소개·배너에 "조용히 제값에 팔아드립니다 — 25년 매수자 네트워크" → 매도 위임 유도
- 기존 지주·공장주 네트워크에 사이트를 디지털 명함처럼 공유

### 오프라인 ↔ 온라인 브릿지
- 명함·현수막에 홈페이지 QR / 방문·전화 손님에게 플레이스 리뷰 요청

### 출시 로드맵
```
[1회·개발자]         사이트 출시 · 검색등록 · 스키마/사이트맵 · 시딩글 10~15 · 매물 6
[1회·개발자+사장님]   네이버 플레이스 · 구글 비즈니스 프로필 최적화
```

## 8. 기술 & 인프라

### 스택
- **프론트:** Next.js(App Router) + Tailwind, 공개페이지 SSG, 디자인 베이스 = 참고사이트 스타일 + 큰 글씨·고대비
- **백엔드/DB:** Supabase (Postgres + Storage + Auth)
- **호스팅/함수:** Netlify (정적 호스팅 + 서버리스 + 예약함수) — Vercel Hobby는 상업적 사용 금지라 제외
- **AI:** DeepSeek API (선불, 저볼륨이라 월 몇백 원 이하). 서버리스 함수 뒤 model-agnostic 추상화로 교체 용이
- **지도:** 네이버 지도 API (매물 핀 · 주소→좌표)
- **데이터:** 공공데이터포털(국토부 실거래가→리포트, 토지이용계획→자동채움) / (선택) 네이버 뉴스 검색 API
- **알림:** 이메일 무료 티어 (옵션 문자)

### 렌더링·배포
- 공개페이지 정적 생성 → 네이버봇 색인 + 빠른 속도 + 저비용
- 매물 저장 시 온디맨드 갱신(ISR) → 해당 페이지만 즉시 반영(전체 재빌드 X)
- 예약함수: 월 1회 리포트 자동 생성·게시 / 매일 Supabase keepalive(7일 미접속 자동정지 방지)

### 데이터 모델(요약)
```
listings   매물 (유형·거래·면적·가격·용도지역·지목·주소·좌표·사진[]·설명·상태·법정표시필드)
posts      콘텐츠 (종류[가이드/리포트]·제목·본문·메타·작성자·게시일)
inquiries  요청폼 (이름·연락처·찾는조건·생성시각·읽음여부)
admin      단일 운영자 인증
```

### 비용
| 항목 | 비용 |
|---|---|
| Netlify · Supabase · 네이버/공공 API · 이메일 | 0원 (무료 티어, 저볼륨) |
| DeepSeek API | 월 몇백 원 이하(선불 충전) |
| **도메인** | 연 ~1.5만원 (유일한 필수 비용, 신뢰·SEO상 권장) |
| (선택) 문자 알림 | 건당 몇십 원 |

→ 사실상 연 1.5만원 + 커피값 수준의 AI 비용으로 운영.

### 유지보수·견고성 (핵심 원칙)
- **핵심(사이트+매물등록+전화)은 정적이라 매우 튼튼** — 거의 안 깨짐
- **취약한 건 자동화(리포트·뉴스·AI)뿐** → 격리 설계로, 자동화가 깨져도 사이트·매물등록·전화엔 영향 0 (새 자동글이 잠깐 안 올라올 뿐). graceful degradation
- 보안: 어드민 인증 + noindex, 폼 스팸 방지(허니팟)

## 9. 명시적으로 제외한 것 (YAGNI / Out of Scope)

- ❌ **지도 기반 일반 공장/토지 검색** — 밸류맵·디스코를 못 이기고 데이터 유지보수 지옥. (대신: 내 매물만 지도 핀 표시)
- ❌ **네이버 부동산·직방·공장나라 등 외부 자동 등록(API/크롤링)** — 공개 API 없음, ToS 위반·계정정지·유지보수 지옥. (대신: 단일 입력 + 링크 공유 + 복사 도우미)
- ❌ **뉴스 스크랩 후 AI 스핀 재게시** — 저작권 침해 + 검색엔진 스팸 패널티 + 신뢰 훼손. (대신: 원본 지역 콘텐츠 + 공공데이터 리포트 + 뉴스는 링크아웃만)
- ❌ **거창한 AI 챗봇** — 고령 고객엔 부적합. (대신: 안내형 '찾는 매물' 요청폼 + 전화)
- ❌ **유료 광고·인스타/유튜브/틱톡·당근** — 예산·노동·타깃 불일치. (파워링크 소액 테스트만 향후 선택)

## 11. 성공 기준

- 사장님이 혼자(또는 최소 도움)로 매물을 등록/수정할 수 있다.
- 주요 지역 키워드 검색 시 네이버 플레이스 + 사이트가 노출된다.
- 수개월간 개발자 개입 없이 방치해도 사이트·매물등록·전화가 정상 동작한다.
- 운영비가 연 ~1.5만원(도메인) + 소액 AI 비용 이하로 유지된다.
- "적게 보여주고 전화로 연결" 흐름을 통해 전화 문의가 발생한다.
