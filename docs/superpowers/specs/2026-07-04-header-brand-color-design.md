# Header Brand Color

## Goal

Apply the primary brand color `#1254CC` to the site header so the global navigation matches the current brand token.

## Scope

- Change the desktop and mobile header background from `bg-navy` to `bg-brand`.
- Change the expanded mobile navigation background from `bg-navy` to `bg-brand`.
- Keep white header text, the gold logo badge, gold hover states, borders, spacing, and behavior unchanged.
- Do not change the footer or other navy content sections.

## Verification

- Add a focused header test that checks the brand background classes.
- Run the header test, full lint, and production build.
- Verify desktop and mobile header rendering in the browser.
