## 1. 시스템 개요

| 구분 | 내용 |
|---|---|
| 프레임워크 | Next.js 16 (App Router), TypeScript |
| 스타일 | Tailwind CSS v4 + shadcn/ui 프리미티브(Button/Card/Badge/Dialog) |
| 데이터 | Supabase(Postgres) `listings` 테이블. 목록 계열 페이지는 빌드 시 정적 생성(`force-static`) |
| 지도 | Naver Maps JS v3 (지오코딩 submodule) |

| 아이콘 | lucide-react |

### 1.1 라우트/렌더링 방식

| 라우트 | 화면 | 렌더링 | 데이터 |
|---|---|---|---|
| `/` | 홈(검색) | Static | 전체 공개 매물(빌드 시) |
| `/listings` | 매물검색 | Static | 전체 공개 매물(빌드 시) |

| `/about` | 회사소개 | Static | siteConfig |
| `/(그 외)` | 404 오류 | not-found | - |
| `/sitemap.xml`, `/robots.txt` | 시스템 | Static | - |

## 2. 공통 규칙

### 2.1 디자인 토큰 (globals.css `@theme`)

| 토큰 | 값 | 용도 |
|---|---|---|
| `brand` | `#0052ff` | 주 강조(브랜드 블루) |
| `brand-dark` | `#003ecc` | 강조 hover |
| `brand-light` | `#eef0f3` | 연한 배경 |
| `ink` | `#0a0b0d` | 본문/제목 |
| `muted` | `#5b616e` | 보조 텍스트 |
| `canvas` | `#ffffff` | 기본 배경 |
| `hairline` | `#dee1e6` | 경계선/구분선 |
| `surface-dark` | `#0a0b0d` | 다크 CTA 밴드 |
| `danger` | `#dc2626` | 경고(파생 destructive) |

- 루트 폰트: `18px`. 라운드 스케일: 카드/버튼 `rounded-md`, 홈 상단 카드 일부 `rounded-lg`, 지도/슬라이더 `rounded-3xl`.

### 2.2 반응형 브레이크포인트 (Tailwind 기본)

| 접두 | 최소 폭 | 주요 전환 |
|---|---|---|
| (base) | 0 | 모바일 1열, 사이드바가 결과 위로 |
| `sm` | 640px | 카드 2열, 유틸리티 바 영업시간 노출, 전화상담 버튼 노출 |
| `md` | 768px | 데스크탑 GNB 노출, 햄버거 숨김 |
| `lg` | 1024px | 검색 2컬럼(결과 + 300px 사이드바), 사이드바 sticky |
| `xl` | 1280px | 카드 3열 |

### 2.3 접근성 원칙

- 루트 18px, 주요 탭 타깃 ≥ 44px(`h-11`/`size-11`).
- 인터랙션 요소에 `aria-label`/`aria-pressed`/`aria-expanded`/`aria-current` 부여.
- 색 대비: ink/muted on canvas, 브랜드 위 흰색.
- 포커스 링(`focus-visible:ring`) 유지. 캐러셀은 `prefers-reduced-motion` 시 자동회전 중지.

### 2.4 상태 표기 규칙

| 상태 | 정의 |
|---|---|
| 로딩 | Suspense fallback(빈 영역) / 지도 "지도 불러오는 중" |
| 빈 결과 | 검색 결과 0건 안내 + 전화 유도 |
| 이미지 없음 | "사진 준비중" 플레이스홀더 |
| 에러 | 지도 로드 실패 안내 + 주소 텍스트 |

## 3. 사이트맵 / 화면 목록

```
행운부동산
├─ 홈(검색)            /
├─ 매물검색            /listings          ← GNB "매물검색" / "매매"(?deal=매매) / "임대"(?deal=임대)
│  └─ 매물상세         /listings/{slug}
├─ 회사소개            /about
└─ 404 오류           (그 외 경로)
```

| 화면 ID | 화면명 | 경로 |
|---|---|---|
| CMN-HEADER | 공통 헤더(GNB) | 전 화면 상단 |
| CMN-FOOTER | 공통 푸터 | 전 화면 하단 |
| SCR-HOME | 홈(검색) | `/` |
| SCR-LIST | 매물검색 | `/listings` |
| SCR-DETAIL | 매물상세 | `/listings/{slug}` |
| SCR-ABOUT | 회사소개 | `/about` |
| SCR-404 | 오류(찾을 수 없음) | 그 외 |

## 4. 공통 영역

### 4.1 CMN-HEADER 공통 헤더(GNB)

- 위치: 전 화면 상단 고정(`sticky top-0`, z-40), 배경 흰색, 하단 hairline.
- 2단 구성(상단 유틸리티 바 + 하단 메인 바).

| No | 영역 | 구성요소 | 유형 | 표시 내용 / 데이터 | 동작 |
|---|---|---|---|---|---|
| 1 | 유틸리티 | 전화 문의 | 링크(tel) | ☎ 문의 032-567-8770 | 클릭 시 전화 발신 |
| 2 | 유틸리티 | 영업시간 | 텍스트 | 평일 09:00–18:00 | (sm 이상 노출) |
| 3 | 메인 | 로고 | 링크(→`/`) | "행" 뱃지 + "공장·창고·토지 전문 중개" + "행운부동산" | 홈 이동 |
| 4 | 메인 | GNB 메뉴 | 링크 그룹 | 홈 / 매물검색 / 매매 / 임대 / 회사소개 | 각 경로 이동(md 이상 노출) |
| 5 | 메인 | 전화상담 버튼 | 버튼(tel) | ☎ 전화상담 | 전화 발신(sm 이상 노출) |

| 7 | 확장 | 모바일 메뉴 | 내비 | 홈/매물검색/매매/임대/회사소개 | 항목 클릭 시 이동 후 메뉴 닫힘 |

- 메뉴 링크: 매매=`/listings?deal=매매`, 임대=`/listings?deal=임대` (매물검색 화면에 필터가 선적용됨).

## 5. 화면별 정의

### 5.1 SCR-HOME 홈(검색)

**개요**: 배너 + 사무소 소개(히어로) + 매물 검색을 한 화면에 통합한 랜딩 겸 검색 페이지. 전체 공개 매물을 빌드 시 정적 로드.

**레이아웃**
```
┌───────────────────────────── Header (CMN-HEADER) ─────────────────────────────┐
│  ┌──────────────────────── 배너 캐러셀 (BNR) ────────────────────────┐        │
│  │  ‹      [ 배너 이미지 1/4, 자동회전, 클릭→네이버 ]      ›   ● ● ● ● │        │
│  └────────────────────────────────────────────────────────────────────┘        │
│  ┌──────────────────────── 히어로 (HERO) ───────────────────────────┐         │
│  │ 공장·창고·토지 전문 중개                          [전화상담][매물보기]│         │
│  │ 인천 서구 공장·토지 전문 부동산                                     │         │
│  │ [대표 공인중개사][사무소 위치][상담 시간][전화 문의]  ← trust strip │         │
│  └────────────────────────────────────────────────────────────────────┘        │
│  ┌──────── 매물 목록 (결과)  1fr ────────┐  ┌──── 사이드바 300px ────┐        │
│  │ 매물 목록            전체 N건          │  │ 매물 검색(필터) [초기화]│        │
│  │ [카드][카드][카드]                     │  │ 종류/거래/평수/가격     │        │
│  │ [카드][카드][카드]                     │  │ 면적 변환기(㎡↔평)      │        │
│  │ (또는 빈 결과 안내)                    │  │ 부동산 유용 사이트(로고) │        │
│  └────────────────────────────────────────┘  └─────────────────────────┘        │
└───────────────────────────── Footer (CMN-FOOTER) ─────────────────────────────┘
```

- 필터(12~15) 변경 → 결과 즉시 갱신 + URL 쿼리 동기화(`?type=&deal=&area=&price=`). 딥링크로 진입 시 필터 선적용.
- 카드 클릭 → `/listings/{slug}`.
- 배너/CTA/전화 → 각 링크·전화.

**상태 정의**: 로딩(Suspense 빈 영역) / 빈 결과(안내) / 이미지 없음(플레이스홀더).
**반응형**: 모바일은 사이드바(필터·변환기·링크)가 결과 위로. lg부터 우측 300px sticky 사이드바.
**SEO·메타**: title 기본값, `RealEstateAgent` JSON-LD.
**연관 파일**: `app/page.tsx`, `components/home/BannerCarousel.tsx`, `components/home/HomeHero.tsx`, `components/listings/ListingSearch.tsx`(+FilterSidebar/UnitConverter/UsefulLinks/ListingCard).

**화면 구성요소**

### 5.3 SCR-DETAIL 매물상세 (`/listings/{slug}`)

**화면 구성요소**

| No | 구성요소 | 유형 | 표시 내용 / 데이터 | 동작 |

| 2 | 이미지 슬라이더 | 캐러셀 | images[] (16:9), 썸네일 | 이전/다음, 썸네일 선택. 사진 없으면 "사진 준비중" |
| 3 | 스펙표 | 정의목록(2~3열) | 종류/소재지/가격/대지면적/건물면적/용도지역/지목/도로/층고/전력/준공 | 값 없는 항목은 자동 생략 |

- **상태**: 이미지 슬라이더(단일/다중), 지도(로딩/정상/에러).
- **메타**: `buildListingMetadata`(제목·설명·canonical·OG 이미지=대표사진 또는 og-default). JSON-LD `Product`(가격 KRW, 재고 상태).

## 8. 화면 흐름(요약)

```
[홈 /]
  ├─(배너 클릭)──────────────→ 네이버 플레이스(외부)
  ├─(매물 보기/#listings)────→ 홈 내 검색영역 스크롤
  ├─(카드 클릭)──────────────→ [매물상세 /listings/{slug}]
  └─(전화상담)──────────────→ 전화 발신

[GNB]
  ├─ 매물검색 ───────────────→ [매물검색 /listings]
  ├─ 매매/임대 ──────────────→ [매물검색 /listings?deal=…] (필터 선적용)
  └─ 회사소개 ───────────────→ [회사소개 /about]

[매물검색 /listings]
  ├─(카드 클릭)──────────────→ [매물상세]
  └─(하단 CTA)──────────────→ 전화 발신

[매물상세]
  ├─(공유)──────────────────→ 링크복사 / 문자
  ├─(지도)──────────────────→ 위치 확인
  └─(문의 CTA)──────────────→ 전화 발신
```
